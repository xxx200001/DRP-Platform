病情预测平台【高精度】技术开发规范（程序员落地版）
0. 核心总原则（全员必须遵守）
本平台所有开发目标只有一个：把模型线上真实 AUC、风险分层准确率做到最高，杜绝实验室高分、线上拉胯。
精准度瓶颈不在大模型，在：数据质量 + 特征工程 + 时序建模 + 严格验证 + 工程防错。
所有模块开发必须优先保证高精度，其次才是功能速度、美观、开发速度。

1. 数据层开发规范（决定 70% 精准度，强制硬核要求）
1.1 数据集硬性标准（算法必须执行）
•禁止只用公开数据集上线（MIMIC、NHANES 只能做预训练、基线测试）
•正式上线模型必须使用：国内真实脱敏随访病历
•单病种训练数据底线：最小 3 万条有效样本，带随访结局标签
•必须带时间维度标签：1年/3年/5年发病、进展、并发症结局
•数据必须去重、去异常、清洗误诊噪声样本
1.2 数据存储与脱敏（后端强制）
•所有用户医疗数据全程脱敏存储，不可存储明文身份证、手机号
•所有训练数据必须去标识化
•数据库必须区分：缺失数据 / 检查过正常 / 检查过异常 三种状态，禁止统一填均值、填0
1.3 线上数据回流机制（后端必须开发）
搭建高精度迭代闭环：
•用户授权后，匿名化保存每次预测输入、模型结果、用户后续随访反馈
•自动沉淀线上真实样本库，用于模型持续迭代
•保存全链路日志：原始输入→结构化数据→特征→模型输出
2. 特征工程强制开发规范（高精度核心，程序员重点做）
禁止直接把原始化验单数据丢入模型，必须做以下所有特征。
2.1 基础特征（必做）
•年龄、性别、BMI、吸烟史、饮酒史、家族史、既往病史
•性别、年龄分层参考区间归一化（不同年龄指标正常值不一样）
2.2 临床衍生特征（高精度关键，必做）
•指标比值特征：AST/ALT、胆红素/白蛋白、血小板/胆红素等临床标准比值
•指标偏离度特征：当前值 & 对应年龄性别参考区间的偏离百分比
•异常标记特征：轻度异常、中度异常、重度异常分级
2.3 时序特征（大幅提升精准度，重点开发）
支持用户多次体检数据，自动计算：
•近3次指标变化趋势（上升/下降/平稳）
•指标变化速率（月度变化量）
•波动方差、最大值、最小值、均值
核心：单次指标不准，趋势才准，必须做时序建模。
2.4 干扰因子剔除（必须做）
•用药标记、近期感染标记、熬夜/临时异常干扰权重降级
•模型特征层区分：一过性异常 vs 持续性异常
3. 算法模型硬性技术规范（算法工程师严格执行）
3.1 模型栈（固定，禁止乱换）
•风险概率预测主模型：LightGBM / Cox-PH 生存分析模型
•文本报告解析、结构化、解释输出：大模型
•禁止使用大模型直接输出风险概率（不稳定、不可复现、精度低）
3.2 必须解决的医疗场景问题
•样本极度不均衡：高危样本少，必须使用 focal loss、分层抽样、权重平衡
•数据漂移监控：线上特征分布偏移自动告警
•可解释性强制开启：每一次预测输出 SHAP 特征贡献度
3.3 预测能力（强功能版）
平台不做简单二分类，做专业预后预测：
•输出：1年/3年/5年 病情进展风险概率
•输出：Top10 风险贡献因子
•输出：风险升高/降低原因、趋势变化解读
4. 工程层高精度保障（后端、前端、OCR必须做）
4.1 OCR + 结构化引擎（精度第一道关口）
•自建检验指标归一化词典，统一所有别名、缩写、大小写
•单位强制校验：mg/L、g/L、mmol/L 自动纠错、量级校验
•异常数值拦截：超生理极限数值直接报错、拒绝入模
规则：上游错一个数据，下游模型全错，必须强校验。
4.2 全链路日志系统（后端必做）
每一次预测永久留存：
•原始上传数据、OCR结果、结构化结果、所有特征值
•模型输出概率、风险等级、SHAP权重
•用于错误样本复盘、模型迭代、问题定位
4.3 模型服务化规范
•模型版本管理，支持 A/B 测试、灰度上线
•线上模型自动监控：AUC、准确率、漂移度、错误案例统计
5. 模型验证规范（杜绝虚高指标，保证线上真实精准）
禁止简单随机划分训练/测试集（会数据泄露、假高精度）
必须三层验证
1.时间拆分验证：旧数据训练、新数据测试（模拟真实预测未来）
2.K折交叉验证
3.外部独立数据集验证（完全未参与训练）
核心评估指标（只看真实有用的）
•AUC-ROC、AUC-PR、C-index（生存模型）
•敏感度（严控漏诊）、特异度
•禁止只看准确率
6. 平台增强功能（强功能版，超出普通预测平台）
在高精度基础上，做行业领先功能：
•病情趋势追踪：多次体检自动生成病情变化曲线、风险走势
•个性化风险归因：明确告诉用户是哪几项指标导致风险升高
•风险分级分层：低/中/高/极高 四级分层，精细预警
•时序对比报告：本次 vs 上次、近3次变化对比
•智能就医建议：根据异常指标精准推荐科室、检查项目
•模型迭代自动更新：线上数据回流自动微调模型
7. 强制合规防风险（技术层处理）
•代码层面禁止输出确诊、诊断、治疗、开药等词汇
•所有结果页强制挂载免责声明
•所有医疗数据接口加密传输、加密存储
8. 开发优先级（直接排期）
第一优先级（决定精准度生死）
1.数据清洗、归一化、缺失值三状态处理
2.临床衍生特征 + 时序特征开发
3.LightGBM/Cox-PH 高精度模型训练与验证
第二优先级
1.OCR结构化强校验系统
2.SHAP可解释性输出
3.全链路日志与错误样本复盘系统
第三优先级（强功能体验）
1.趋势分析、对比报告、风险归因、随访回流
2.模型监控与自动迭代
9. 最终技术效果承诺（可直接对团队立目标）
按照以上规范开发，可实现：
•慢病病情风险预测 线上真实 AUC ≥ 0.82~0.88
•极低漏诊率、风险分层精准、趋势预测可靠
•远超市面普通AI问诊、简易预测平台的精度
